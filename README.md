Tentang

Alight Motion Generator adalah project berbasis JavaScript yang dibuat untuk mempermudah proses pembuatan data atau output yang berhubungan dengan Alight Motion.

Project ini dibuat dengan pendekatan yang sederhana dan ringan, sehingga dapat dijalankan langsung menggunakan Node.js tanpa framework yang berat.

---

Fitur

- Berbasis JavaScript
- Dapat dijalankan melalui Node.js
- Struktur project sederhana
- Tidak membutuhkan framework frontend
- Cocok untuk eksperimen dan pengembangan lebih lanjut
- Source code mudah dimodifikasi

---

Persyaratan

Sebelum menjalankan project, pastikan sudah memiliki:

- Node.js
- Git

Cek versi Node.js:

node -v

Cek Git:

git --version

---

Instalasi

Clone repository:

git clone https://github.com/johsua092-ui/alight-motion-generator.git

Masuk ke directory project:

cd alight-motion-generator

Jika project menggunakan dependency, install terlebih dahulu:

npm install

---

Menjalankan

Jalankan file JavaScript menggunakan Node.js:

node alightmotion.js

Jika nama file utama berbeda, sesuaikan command dengan file yang tersedia di repository.
